# Getting Started with ESG application

# Technologies Used
1. HTML5
2. CSS3 - css library (Sass)
3. Javascript (Ecmascript 2022)
4. React js 
5. Node js (Run time environment for React application)
6. Package Manager - Yarn

# Project Setup
1. Clone this repository from git hub
2. Run `yarn install`
3. Run `yarn run build:dev`
4. Run `yarn run dev` to run the application

for uat 
1. Run `yarn run build:prod`
2. Run `yarn run start` to run the application

# Git Guidelines

## Branching

- Environment Branches
- dev - Developer can deploy and test their features

## Do's & Dont's

1. Do not commit package-lock.json file, this project follows yarn
2. Commit yarn file only when you install new package or you change version of any package

## Naming convention

- Folders should be Capitalized
- Files should be Capitalized
- variables should follow CamelCase (Note: it should not contain special characters (or) numbers)
- stylesheets should be named in small letters without special characters (Note: hypens can be included)
- Asset files should be named in small letters wihtout special characters (Note: hypens can be included)

**Note:** No files should have space in their names
